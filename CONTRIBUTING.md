# Contributing to the Remote jobs list

Help remote job seekers find roles they can actually apply for. Employer pages may set location limits, so include those when you can.

## What belongs in this list

Remote software, support, sales, marketing, operations, and other roles belong here when the employer says the work can be done remotely.

## Suggest a job

Include the exact role title, employer's own apply link, and any stated remote location limits.

[Open the Add a job form](https://github.com/Jobhacki/remote-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the role title, employer, link, and whether the page is missing or says the role is filled.

[Open the Report a dead link form](https://github.com/Jobhacki/remote-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
